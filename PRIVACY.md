# Privacy / Конфиденциальность

## English

This is a public repository. Posts, attachments and commit history can be copied or indexed. Deleting a file later does not reliably remove all copies.

Share only the model, relevant public software/source versions, test method, expected result, observed result and a short manually reviewed, redacted error excerpt when necessary.

Do not upload configuration exports, backups, firmware taken from a personal installation, packet captures, full logs, subscription URLs, VPN/proxy endpoints, credentials, API keys, cookies, account/device identifiers, MAC addresses, household hostnames, personal IP/DNS addresses, precise location or screenshots containing QR codes and account details. A hashed identifier can still be linkable; do not substitute hashes for unnecessary identifiers.

Use neutral labels such as `client-A`, `router`, `VPN-endpoint` and `test-domain`. Keep the public source revision and software version intact. Review attachments and every file in a commit, not just the visible text of a post.

If a credential is accidentally exposed, revoke or rotate it with its provider first. Removing the post or rewriting Git history alone does not make an exposed credential safe. Do not paste the credential into an issue asking for help.

Published firmware would require a separate clean build with no personal overlay, password hashes, SSH keys, subscriptions, certificates/private keys or device-specific data. No such release is provided here.

## Русский

Репозиторий публичный: записи, вложения и история коммитов могут копироваться и индексироваться. Последующее удаление файла не гарантирует удаления всех копий.

Публикуйте модель, нужные публичные версии программ и исходников, способ проверки, ожидаемый и фактический результат. При необходимости добавьте короткий фрагмент ошибки после ручной проверки и удаления приватных данных.

Не загружайте экспорты конфигурации, резервные копии, образ личной установки, сетевые дампы, полные журналы, ссылки подписок, адреса VPN/proxy-серверов, пароли, API-ключи, cookies, идентификаторы учётных записей и устройств, MAC-адреса, имена домашних устройств, личные IP/DNS-адреса, точное местоположение и снимки с QR-кодами или данными аккаунта. Хеш тоже может позволять сопоставление; ненужные идентификаторы лучше полностью убрать.

Обозначайте устройства как `client-A`, `router`, `VPN-endpoint`, `test-domain`. Публичную ревизию исходников и версию программы сохраняйте точно. Проверяйте вложения и весь состав коммита.

Если секрет случайно опубликован, сначала отзовите или замените его у соответствующего провайдера. Одного удаления записи или переписывания истории Git недостаточно. Сам секрет нельзя добавлять в обращение за помощью.

Для распространения прошивки нужна отдельная чистая сборка без личного overlay, хешей паролей, SSH-ключей, подписок, закрытых ключей сертификатов и данных экземпляра устройства. Здесь такого релиза нет.
